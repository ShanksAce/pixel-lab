## AI 產出與調整（代理內部工程歷程，非偽造使用者 Prompt）

1. 取得題目：登入後讀取四大功能、PDF 四章與評分表。瀏覽器曾出現連線錯誤，重設連線後讀取成功。
2. 規劃：採瀏覽器 JavaScript App；避免伺服器傳送影像；以 Tiny Face Detector 取得真實模型信心分數。決定固定版並將模型放在網站內，避免每次依賴外部 CDN。
3. 實作：建立 core.mjs、app.mjs、filter-worker.mjs、HTML/CSS、12 個數值測試、說明文件與部署 workflow。
4. Refinement / 演算法：明確使用 180° 翻核的 convolution，並用非對稱 kernel 測試與 correlation 區分；RGB MSE 避免 alpha 混入；MSE=0 顯示 Infinity。
5. Refinement / 實際測試失敗：第一次 12 項測試有 1 項失敗，原因是空白矩陣被 JavaScript Number('') 轉成 0。加入 trim 後空字串檢查，再跑 12/12 通過。
6. Refinement / 數值防呆：限制奇數方陣、有限數值、矩陣大小、近零權重總和、bias 範圍；保留原圖，不以累積濾波結果覆寫。
7. Refinement / 執行環境：預覽起初因沙箱網路存取失敗；在授權執行環境重新啟動預覽後 Chrome 成功載入。
8. 實測高斯：960×540 自製色彩圖，MSE 23.3688、PSNR 34.444 dB，保留截圖。
9. Refinement / 人臉參數：官方四人範例在 416 / 0.50 找到 3 張；改用 608 / 0.30 找到 6 張，顯示過低門檻引入誤檢；改用 608 / 0.70 找到 4 張。報告保留三組結果，不以單張結果宣稱通用準確率。
10. GitHub：連線工具可識別 ShanksAce，但受限網路下 CLI 驗證失敗且瀏覽器尚未登入，請使用者自行登入後再完成建立儲存庫。
